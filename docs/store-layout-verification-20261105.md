# 单页商店实现与验收

## 范围

左侧个人栏增加“商店”，入口为 `/d2s/store`。正式授权、付费解绑和离线延长包采用价格、说明和功能清单卡片；选择商品、授权和付款方式、核对金额及确认支付均在同一页。授权管理保留设备操作及商店链接，钱包不再嵌入授权购买表单。

价格来源于服务端共享函数 `D2SProductPrice`，没有在前端复制收费数值。商品目录接口仅供已登录账号读取，购买关闭时仍可浏览。正式授权现有价格为 CNY 99.00 / USD 29.90；解绑沿用三次阶梯价；离线延长包从现有配置读取价格，缺失币种不展示零元。

## 自动验证

- `go test ./controller ./model ./router ./middleware ./service -count=1` 通过，覆盖原有订单与支付回归。
- 新增定价回归：正式授权、三次阶梯解绑、离线包、非法币种及未配置价格。
- 商品目录回归：购买关闭时可浏览价格、无配置币种不显示零元；路由验证未登录请求返回 401。
- 前端购买回归覆盖：浏览不下单、同页核对与确认、余额全额支付、选择授权、支付宝首位默认选择、不支持渠道过滤、价格变动、商品/付款方式变更使报价失效、并发操作禁用、失败重试沿用幂等键、目录/报价加载失败和关闭购买。
- 前端相关 13 个测试文件共 58 项通过；TypeScript、改动文件 Oxlint、生产构建和 `git diff --check` 通过。
- 本次不改变数据库表结构、迁移或 SQL 读写，定价抽取保持原有收费规则。

## 浏览器验证

本机 Edge/Playwright 使用隔离 API 数据完成：

1. 从授权管理点击个人栏“商店”，确认只有一个商店入口及购买页面。
2. 三列价格说明卡片；支付宝默认选中。
3. 选择付费解绑及授权，确认前无订单；核对实际 CNY 34.90 后才创建测试订单，保留报价及幂等键。
4. 确认支付在本站 iframe 打开隔离收银台，未跳转购买页面。
5. 钱包不显示商品选择器；390px 手机布局单列，页面和内容区均无横向溢出；无浏览器运行异常。

测试收银台及订单均为本地 fixture，没有真实付款、退款或账单验收，也没有修改生产购买总开关。
