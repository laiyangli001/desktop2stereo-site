# 真实身份核验适用范围书面意见请求

**文件状态**：供运营主体与法律顾问/主管部门核对的事实清单，不构成法律意见  
**整理日期**：2026-11-03  
**适用网站**：d2s.site

## 1. 请求目的

请法律顾问或有权主管部门依据下列实际业务和服务流程，书面判断网站运营主体是否以及在何种范围内承担真实身份信息核验义务。该书面意见是网站提交自评估前的待办材料；本清单本身不作适用或豁免结论。

## 2. 已由运营负责人说明的业务事实

以下事实来自运营负责人陈述，尚未独立核验营业执照、备案材料、合同或线上配置：

- 运营主体位于山东省烟台市；公司工商经营范围包含“软件开发”。
- ICP 备案服务类别目前不清楚；“软件开发”不是负责人确认的 ICP 备案类别。
- 网站只销售运营主体自己的 Desktop2Stereo 软件，不接受第三方或用户上架交易。
- 网站不托管 Desktop2Stereo 安装包；下载入口跳转到 GitHub、夸克网盘或百度网盘等外部地址。

## 3. 网站当前服务流程

以下内容以当前产品规格和实现记录为基础，正式出具意见前应由运营方与顾问共同复核线上版本：

- 用户使用电子邮箱注册、验证邮箱并登录，账户用于购买软件、管理订单和授权。
- 网站提供自有软件介绍、在线下单/支付流程和下载入口；网站记录订单及与账户关联的购买信息。付款渠道由实际部署配置决定，代码支持多个渠道不等于这些渠道均已在生产启用。
- 登录用户的下载点击经过站内白名单路由记录后跳转到外部文件地址；匿名用户仍可使用公开下载直链，该路径不关联账户，不能证明外部文件实际传输完成。
- 网站不提供面向公众的用户内容发布、评论、群组或站内即时通讯功能。
- 已登录用户可向运营方提交私密服务工单，描述付款、订单/授权、下载、账户或软件使用问题；工单不对其他用户或社会公众展示。网站还提供跳转到企业微信客服的链接；该外部服务的数据处理主体和处理范围需单独核实。
- 邮箱验证码只验证邮箱控制权，不是公民身份或真实身份核验。当前证件录入页面和 API 已停用，注册不收集证件号码或影像；不得据此向外宣称“已实名”或“确定无需实名”。

## 4. 需要区分的条文触发条件（初步梳理，不构成法律结论）

- 《反电信网络诈骗法》第二十一条第四项分别列出“信息、软件发布服务”和“网络交易”等服务，并规定提供这些服务时应要求用户提供真实身份信息。根据已确认的商品展示、订单、付款与授权交付流程，网站具有明显的网络交易属性，应将该条实名核验适用性视为实质性风险并优先取得书面意见，不能按“身份义务大概率不适用”准备自评估。仅销售自有软件、没有第三方上架及安装包由外部平台托管，可能影响“软件发布/分发服务”的定性，但不能据此排除网络交易这一独立触发项。具体义务主体、账号覆盖范围、核验时点及境外用户可用方式，仍须结合运营主体、交易合同、支付和交付流程由顾问或主管部门书面判断。
- 《反电信网络诈骗法》第二十三条针对为应用程序提供封装、分发服务的主体，要求登记并核验应用开发运营者身份及应用功能、用途。本站不托管安装包、只跳转外部地址，是判断本站是否实际提供封装/分发服务的重要事实，但链接由谁选择和控制、下载页面和交付路径由谁运营等事实仍需核对，不能单凭“外链”作豁免结论。
- 《互联网用户账号信息管理规定》第九条将真实身份认证义务对应到提供信息发布、即时通讯等服务的相关账号；本站没有公开内容发布、评论、群组或站内即时通讯功能，这一点支持不属于该条列明服务的初步分析。与此同时，该规定第二十三条把应用软件下载列入互联网信息服务提供者的定义范围。定义条款与第九条的具体触发服务如何适用于本站账号和外链下载，需要书面解释，不能把“没有 UGC”直接推导成所有法律下均无实名义务。
- 《网络安全法》第二十六条列明网络接入、域名注册、电话入网、信息发布和即时通讯等服务的实名要求；网站无公开发布和即时通讯功能是相关判断因素，但仍需与其他法律中的网络交易、软件发布条款分别分析。
- “软件开发”是工商经营范围，不等于 ICP 备案服务类别或行政许可结论。备案主体、服务内容、备案号及是否另有许可，应以备案系统和正式材料核实。

以上仅是基于目前描述的条文结构和风险点，不判断本网站是否属于相关义务主体，也不对个人用户、境外用户、匿名访客或购买用户作豁免结论。

## 5. 请书面逐项答复

1. 结合运营主体法律身份、实际 ICP 备案/许可类别、服务地域和上述业务流程，运营主体是否属于相关法律所称的“互联网服务提供者”或其他承担核验义务的主体？请说明依据。
2. 网站仅销售自有软件、由外部平台托管安装包并提供跳转链接，是否构成或涉及《反电信网络诈骗法》第二十一条第（四）项所列“信息、软件发布服务”或“网络交易”服务？请分别分析商品展示、下单、支付、授权交付、下载跳转各环节；如结论不同，请说明分别对应的义务。
3. 《互联网用户账号信息管理规定》第二十三条将“应用软件下载”列为互联网服务示例，而第九条将真实身份认证义务表述为面向提供信息发布、即时通讯等服务的注册账号。请分析本网站仅提供外部下载链接、并有登录后下载点击记录的模式是否落入相关定义和具体义务；邮箱账号、私密客服工单及跳转企业微信分别如何影响判断？
4. 《反电信网络诈骗法》第二十三条规定为应用程序提供封装、分发服务的主体应登记并核验开发运营者身份以及应用功能、用途。网站不托管安装包、只跳转外部地址是否属于该条所述分发服务，还是仅属外链导流？请结合实际控制下载页面、链接和用户路径作出分析。
5. 如存在核验义务，义务覆盖哪些主体和用户类型（包括境外用户、仅访问公开下载页面的访客、注册用户、购买者及客服人员）？核验应发生在注册、下单、付款、授权交付或其他哪个时间点？
6. 对没有中国大陆手机号或身份证件的境外用户，允许采用哪些合规核验方式、身份凭证或服务流程？是否可以提供受限的替代路径；不得仅要求填写未经核验的邮箱作为替代结论。
7. 如需收集或调用身份信息，请明确合法处理依据、最少字段、告知与单独同意要求、第三方核验服务条件、跨境传输要求、访问权限、安全保护、保存期限和删除/更正机制。证件明文、影像或号码哈希各自是否允许、是否必要，也请分别说明。
8. 请区分必须采取的法定义务与建议性风控措施，并指出需补齐的主体登记、ICP 备案/许可、支付渠道或其他资料。

## 6. 建议随书面咨询提交的核验材料

- 运营主体营业执照、完整工商登记名称和统一社会信用代码。
- d2s.site 的 ICP 备案主体、备案服务内容、备案号及任何相关许可材料；如无法确认，请先从备案系统调取。
- 网站线上产品介绍、账户注册、下单、支付、授权、下载和客服流程截图或录屏；标明哪些页面要求登录。
- 运营主体与用户的销售/服务协议、订单与支付流程说明，以及目前生产启用的支付渠道清单。
- GitHub、夸克网盘、百度网盘下载链接的控制者、文件托管位置及链接与订单/账户的关系。
- 企业微信客服入口的实际服务主体和用户跳转后的数据处理说明。
- 用户行为日志、注册快照、订单和支持工单的数据字段、用途、留存期限及访问角色说明。

## 7. 书面意见归档要求

请在正式意见中记录出具方、出具人/审核人、日期、适用的运营主体、审阅过的业务材料、适用法律条款、事实假设、结论及其适用边界。若材料不足，请明确列出待补事实，不要将未核实事项写成已确认结论。

运营负责人收到意见后，应将原件或可验证的正式文件归档，并据此更新服务端门禁、隐私告知和自评估材料。取得并审阅书面意见前，继续保持证件核验入口关闭，不新增证件数据收集，不提交自评估，也不宣称邮箱验证等同于实名或本站当然豁免。

## 8. 官方法规来源

- [工业和信息化部：《中华人民共和国反电信网络诈骗法》第二十一条第（四）项、第二十三条](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_d30139b442a141f48f05775d8c0b3cee.html)：分别列出信息/软件发布及网络交易等服务的真实身份信息要求，以及应用程序封装/分发服务的核验要求。
- [中央网信办：《中华人民共和国网络安全法》第二十六条](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm)：规定特定网络接入、域名注册、电话入网、信息发布和即时通讯服务的身份信息要求。
- [中央网信办：《互联网用户账号信息管理规定》第九条、第二十三条](https://www.cac.gov.cn/2022-06/26/c_1657868775042841.htm)：第九条规定信息发布、即时通讯服务相关账号的真实身份认证；第二十三条将应用软件下载列为互联网信息服务示例。两条如何适用于外链下载与本网站账号，应由书面意见区分分析。

本文件仅列出核验事项和官方条文出处；具体条文如何适用于本网站，须由具备事实材料的法律顾问或主管部门书面判断。
