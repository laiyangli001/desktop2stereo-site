# new-api 复用与差距分析

基线：`QuantumNous/new-api@3a9f41ee85cc369f5b8d7fe6e62ff4e7bf3a9ec8`。

| 需求域 | new-api 基线 | Desktop2Stereo 处理 |
|---|---|---|
| 注册、登录、退出、密码重置 | 已有 | 直接复用，并提供 `/api/v1/auth/*` 兼容入口 |
| 邮箱验证、Turnstile、限流 | 已有 | 直接复用；生产必须启用邮箱验证 |
| JWT、刷新令牌轮换、重放处置 | 已有 | 设备码兑换后签发同一套安全会话 |
| OAuth、Passkey、2FA | 已有 | 保留，用户中心可继续使用 |
| 管理员鉴权与写操作审计 | 已有 | Desktop2Stereo 管理 API 使用同一中间件 |
| Stripe、Creem、易支付、Waffo | 已有充值/订阅适配 | 复用渠道验签和收银台，验签后转为统一 D2S 支付事件 |
| PayPal、Paddle | 无 | 保留统一支付桥接口，待增加渠道适配器 |
| 邀请码 | 已有 `aff_code`、`inviter_id` | 复用归属字段，新增一次性首购奖励和冲正记录 |
| 通用钱包 | 已有 quota 钱包 | 授权业务需要 CN/INTL 分币种账务，新增独立不可变流水 |
| 试用和多授权 | 无 | 新增 30 天试用及一账号多份单设备授权 |
| 设备码登录 | 无 | 新增申请、批准、轮询、取消和单次消费状态机 |
| 离线凭证 | 无 | 新增 P-256 ES256 紧凑 JWS 和签发记录 |
| 在线租约 | 无 | 新增 15 分钟租约、5 分钟心跳和并发占用拒绝 |
| 撤销、永久绑定、人工解绑 | 无 | 新增状态机、冷却期、阶梯订单和终身一次人工解绑 |
| 区域锁定 | 无 | 首次成功外部付款原子锁定 CN/INTL |
| CN 提现 | 无 | 新增 CNY 余额预留和管理员审核 |

## 不直接复用的部分

new-api 的 quota 使用量钱包服务于 AI API 计费，不具备 ISO 货币、分币种、提现、负余额
和授权订单快照语义，因此没有强行复用为授权账本。两套账务表彼此隔离，可由管理后台统一展示。

原计划的 Astro + Cloudflare Workers + D1 架构不再成立。新项目的权威服务改为 Go/Gin +
GORM + PostgreSQL/MySQL/SQLite，Cloudflare 只承担 DNS、CDN、WAF 和可选支付回调边缘中转。
